Chromeで、実際にビルドしたHTML/CSS/JSをiframeの各幅で表示しました。予約・管理・MY PAGEにはブラウザ内のテストデータを使用し、本番APIへの書き込みは行っていません。テスト画面・データ・モックはZIPには含めていません。

| HOME・SCHEDULE・RULES・RANK・REPORT・BOOKING・ADMIN・MY PAGE | 1920 / 1440 / 1280 / 1024 / 768 / 720 / 480 / 390 / 375 / 320pxのフレーム幅 | 全幅でbodyの横はみ出しなし |
| RULES | PC・390pxの画像、見出し、本文、3本線メニューの開閉 | 表示・展開状態の切替を確認 |
| RANK | 320px・390pxの縦型選択、GOATへの切替 | 選択状態・表示更新を確認 |

## 削除・上書きについて

削除したソースファイルはありません。古い画像を参照するHTMLだけを整理しており、他の参照先を壊さないよう素材ファイルは維持しました。したがって、上書き後に手動削除が必須の旧ソースファイルはありません。

ZIPには `.git`、`node_modules`、`.env`、`.openai`、`dist`、生成済み`assets/css`、テスト用モック、古い版の入れ子フォルダを含めていません。CSSと公開用distはビルドで作成してください。

## GitHubへの反映手順（確認後に実施）

1. 現在のリポジトリで作業ブランチを作り、未保存の作業があれば先に退避します。
2. ZIPを展開して、`index.html`や`package.json`がリポジトリ直下へ来るよう上書きします。外側にownpaceフォルダはありません。既存`.git`は削除しません。
3. Node 22で `npm ci` → `npm run build` → `npm run check` → `npm test` を実行します。
4. `npm run dev` で表示を確認します。直にHTMLを開かず、表示されたローカルURLを使用します。
5. iPhoneとLINE内ブラウザでログイン・予約確認・取消・MY PAGE・固定スクロールを確認します。
6. `git diff`を確認し、承認後にCommit / Pushします。既存GitHub Actions設定は変更していません。

本パッケージのためにSupabaseへの追加デプロイやSQL実行は不要です。元の運用環境のバックエンドが正常稼働していることは別途必要です。
