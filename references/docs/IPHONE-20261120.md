# iPhone向け固定スクロール・ヘッダー修正

- スマホはブラウザー標準のposition:stickyで5つの場面を固定し、スクロール位置で内容を切り替えます。GSAPのfixedピンとスペーサーはPCのみ。
- スマホの高さ640px未満という一律の無効条件を外し、実際の本文が画面に収まるかで判定します。小さい画面では文字・余白を少し詰め、読み切れない極端に低い横画面は通常スクロールに戻します。
- 100svhを使い、600pxの最低高さをスマホ固定エリアに適用しません。ツールバーによる縦リサイズでは固定処理を作り直しません。
- ヘッダーは56px＋上部セーフエリア。ロゴと44pxのMENU操作を固定表示し、MOTION切替はメニュー内へ移動。
- ノッチ・ホームインジケーター領域に対応。全ページにviewport-fit=coverを設定。
- CSS・JSに内容ハッシュのクエリを付け、更新前のファイルが残る問題を軽減。ソースファイルの参照パスは維持し、ビルド時のみ付与。
- PCの既存GSAP演出、FAQ、ルール・文章、リンク先は維持。MOTION OFF・OSの動きを減らす設定では通常スクロールに戻ります。

## 確認

Chrome内のスマホ相当フレームで幅320・375・390・430px／高さ568px、幅320・375・390px／高さ600pxを確認。全てnative stickyが有効で、ヘッダー56px・場面はその直下に固定。本文と切替ボタンの重なり・横はみ出しなし。実際のホイールスクロールでABOUTからRULESへ進み、固定位置56pxを保つことを確認。MOTION OFFとメニューの開閉も確認。

iPhone実機・Safariエンジンによる確認は未実施。
