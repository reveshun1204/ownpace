# 画像について

添付ZIP内の6点は文字が入った小さなコンセプト画像のため、そのまま本番の写真には使用していません。
内蔵の画像生成で、新しいブランド背景を3点制作しました。実際の会場やサークル活動を撮影した写真ではありません。
構図は生成結果のまま、Web向けに1536px / 768px幅のWebPへ変換しています。文字やロゴを焼き込んでいません。

- `sunset-*.webp`: 夕焼け、海、右側のバスケットゴール。HOME FV / ABOUT / RULESのブランド背景。
- `daylight-*.webp`: 昼の海辺のコート。HOW TO JOIN / SCHEDULEの装飾背景。
- `night-*.webp`: 夜の海辺のコート。MEMBERSHIP / RANK / FINAL CTAの装飾背景。

REPORTページとHOMEのACTIVITY REPORTシーンには、生成画像を活動写真として掲載していません。
正式ロゴは未提供です。既存ロゴの生成・描き直しは行っていません。
